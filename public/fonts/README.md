# General Sans (UI and body font)

General Sans is a Fontshare font (ITF Free Font License). It is not on npm or Google Fonts, so
download it yourself and drop one file here:

1. Open https://www.fontshare.com/fonts/general-sans and click **Download family**.
2. In the zip, open the `WEB` folder and copy **`GeneralSans-Variable.woff2`** into this folder:
   `public/fonts/GeneralSans-Variable.woff2`
3. Restart `npm run dev` / redeploy.

Until the file exists the site falls back to the system sans-serif.
